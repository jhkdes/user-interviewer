# Glossary — AI Voice User-Interviewer

Shared vocabulary for the MVP. Use these terms consistently across requirements, design, and code (entity/table/variable names should map to these where practical).

| Term                                     | Definition                                                                                                                                                                                                                                                               |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **PM**                                   | The product manager (or teammate) using the dashboard to run research. The tool's primary/only authenticated user role in the MVP.                                                                                                                                       |
| **Study**                                | A single research effort created by a PM: a target-profile description plus one shareable link. A study can have many Participants/Interviews under it.                                                                                                                  |
| **Target Profile**                       | The plain-English description a PM provides when creating a Study — industry, years of experience, job title, seniority, and overall responsibility of who they want to talk to. Describes the _type_ of person, not a named individual.                                 |
| **Study Link**                           | The single reusable URL generated for a Study. Shared broadly by the PM (email, Slack, etc.) to reach multiple people matching the Target Profile. Each person who opens it starts their own independent Interview within that Study.                                    |
| **Participant**                          | A person who opened a Study Link and provided their name/email to begin an Interview. Treated as a research partner, not just a subject — the intent is ongoing relationship (thank-you, shared learnings, possible future invites), not a one-off anonymous respondent. |
| **Interview**                            | One Participant's individual session within a Study: the voice conversation plus its resulting Transcript, Recording, and Individual Summary. Also referred to as a "session."                                                                                           |
| **Interview Agent** / **AI Interviewer** | The voice AI that conducts the Interview — greets the Participant, runs the broad-to-narrow discovery conversation, and decides when to end it.                                                                                                                          |
| **Recording**                            | The full audio capture of an Interview.                                                                                                                                                                                                                                  |
| **Transcript**                           | The full speaker-labeled text record of an Interview, derived from the Recording.                                                                                                                                                                                        |
| **Individual Summary**                   | The AI-generated summary of a single Interview — key pain points, notable quotes, and takeaways for that one Participant.                                                                                                                                                |
| **Study Report**                         | The cross-participant analysis across all completed Interviews in a Study, generated on demand by the PM. Surfaces shared themes/pain points and how many Participants raised each one. Distinct from an Individual Summary, which covers only one Interview.            |
| **Consent Screen** / **Intro Screen**    | The step a Participant sees before the mic activates: explains the study's purpose, that the session is recorded, that name/email are collected to follow up, and requires an explicit agree action.                                                                     |
| **Thank-You Email**                      | The automated email sent to a Participant shortly after their Interview completes.                                                                                                                                                                                       |
| **Depth Heuristic**                      | The Interview Agent's rule for how far to probe a pain point (one to two follow-up layers) before going deeper or pivoting to a new thread.                                                                                                                              |
| **Termination Condition**                | The rule for ending an Interview: the Agent judges sufficient depth has been reached on one or more pain points, or a hard 20-minute cap is hit — whichever comes first.                                                                                                 |
| **Study Status**                         | Open or Closed. A Closed study's Link no longer accepts new Interviews.                                                                                                                                                                                                  |
| **Interview Status**                     | Pending, In-Progress, Completed, or Expired — the lifecycle state of a single Interview.                                                                                                                                                                                 |

## Terms intentionally avoided (and why)

| Avoid                        | Use instead                             | Why                                                                                           |
| ---------------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------- |
| "Session" (alone, ambiguous) | Interview                               | "Session" is fine informally but Interview is the canonical entity name.                      |
| "Respondent" / "Subject"     | Participant                             | The product framing is partnership, not passive data source.                                  |
| "Survey" / "Questionnaire"   | Interview                               | This is an open-ended conversation, not a fixed question set.                                 |
| "Project" / "Campaign"       | Study                                   | Keep one consistent name for the top-level research container.                                |
| "Aggregate Summary"          | Study Report                            | Distinguish clearly from Individual Summary.                                                  |
| "User" (unqualified)         | PM or Participant, always specify which | "User" is overloaded — could mean the PM using the tool or the target user being interviewed. |
